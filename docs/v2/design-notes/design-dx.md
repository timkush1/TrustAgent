# TrustAgent v2: DX, configuration, docs and ops design spec

**Scope.** This spec covers configuration and its layering, the developer tools (`configure`, `doctor`, `demo`, `calibrate`, `record-demo`), Compose, the Makefile, Dockerfiles, CI/CD, docs, versioning and the git workflow.

**Owned by other designers.** I use their work but don't define it:
- gate semantics and the `X-TrustAgent-*` headers;
- the Jev adapters' call logic;
- the cascade verifier;
- the dashboard pages.

Where I pin down something they need (the config shape, the policy file, the admin API), it is marked **[contract]**.

**Assumption markers.** `[A#]` marks an assumption that must be checked during implementation. Everything else was checked against the working tree on 2026-09-27.

## 1. Configuration model

### 1.1 Layers and precedence

Keys fall into two classes.

- **Boot keys:** secrets, ports, URLs, backend selection, infrastructure. They come **only** from the process environment (with `.env`), and changing one needs a restart.
- **Runtime keys:** gateway policy, thresholds, Jev sample rate and budget, cascade tuning. They live in one **policy document**, which can be edited live.

```
Boot keys:    built-in default  <  .env (dev loader)  <  real process env / compose environment:
Runtime keys: built-in default  <  env "seed" (e.g. TRUTHTABLE_GATE_DEFAULT_MODE)
              <  newest policy version, whichever source it came from:
                   config/policies.yaml   (source=file)
                   dashboard edit in DB   (source=dashboard)
```

**Rules.**
1. **The real environment always beats `.env`.** Standard dotenv behaviour: the loader never overwrites a variable that is already set.
2. **The Go proxy is the single authority for runtime keys.** The Python engine never reads `policies.yaml`. Per-audit tunables reach it in `AuditRequest.options` **[contract with the engine designer: `map<string,string> options = 10` or a typed `AuditOptions` message]**. Python therefore needs no database driver and can never disagree with Go.
3. **Policy versions are append-only.** The active version is the **newest** one, whether it came from the file or the dashboard. A changed file (new sha256) creates a new `source=file` version, so it wins over an older dashboard edit. A dashboard edit made after that wins until the file changes again. Every version can be rolled back and diffed.
4. **`TRUTHTABLE_CONFIG_LOCK=true`** makes the file the only authority. The dashboard becomes read-only and `PUT` returns `423 Locked`. This is for GitOps or production.
5. **Secrets are never editable or readable from the dashboard** (ADR-009). The UI shows set/unset, a masked hint (`sk-or-v1-…9f2c`), and a **Test connection** button that runs the probe server-side.
6. **Least privilege per service in Compose.** Keys are passed explicitly under `environment:`, never through `env_file:`. The dashboard container gets no keys at all.
7. **Without Postgres,** dashboard edits apply in memory. The API returns `persisted:false`, and the UI says "applies until restart (no database configured)". Nothing pretends to be saved.

### 1.2 Loading mechanics

**Go** (new `internal/config/dotenv.go`, no dependencies).
- `FindDotenv(start)`: returns `$TRUTHTABLE_ENV_FILE` if set (an empty value disables loading). Otherwise it walks up from the working directory to the first directory that contains `VERSION` or `.git`, and uses `<that>/.env` if it exists.
- The parser accepts `KEY=v`, `export KEY=v`, and single- or double-quoted values (with `\n` escapes in double quotes). ` #` starts a comment only in unquoted values. It tolerates CRLF, never overwrites existing env, and returns the keys it loaded, which are logged by name only.
- In containers there is no `.env` inside the image, so the loader does nothing.

**Python.** `config.py` computes `ENV_FILES = (TRUTHTABLE_ENV_FILE,)` when that variable is set. Otherwise it uses `(<repo_root>/.env, ./.env)`, where the repo root is the first parent of `Path(__file__)` that contains `VERSION`. pydantic-settings skips files that don't exist, and later files win. Add `extra="ignore"`.

**Upstream shorthand.** `TRUTHTABLE_UPSTREAM_URL=ollama` means "the Ollama that `OLLAMA_BASE_URL` points to". Compose sets `OLLAMA_BASE_URL=http://ollama:11434` for the proxy; the dev default is `http://localhost:11434`. That lets one `.env` work both in Docker and on the host.

**Invalid values.** Every parse failure becomes a `Warning{Key, Message, Hint}`, for example `TRUTHTABLE_JEV_TIMEOUT="abc": not a duration (e.g. 800ms); using default 1s`. Warnings are logged at startup and served by `/api/admin/config`. `TRUTHTABLE_STRICT_CONFIG=true` turns warnings into a startup failure with exit 2; CI and e2e set it.

**Unknown or misspelled keys.** Any `TRUTHTABLE_*` variable that isn't in the registry produces the warning "unknown key TRUTHTABLE_JEV_MODLE — did you mean TRUTHTABLE_JEV_MODEL?" (Levenshtein distance ≤ 2). Python does the same for the `TRUTHTABLE_JEV_` prefix and its own unprefixed keys.

**Deprecated aliases.** Read them and warn once:
- `UPSTREAM_LLM_URL` → `TRUTHTABLE_UPSTREAM_URL`
- `REDIS_URL` → also accepted as `TRUTHTABLE_REDIS_URL`

### 1.3 Go interfaces

```go
// internal/config/registry.go — single source for docs, masking, unknown-key checks
type Kind int // String, Int, Bool, Float, Duration, List, URL, Secret, Enum
type Key struct {
    Name, Default, Group, Description string
```

```go
// internal/policy — the document [contract: the gateway designer owns field semantics]
type Document struct {
    Version  int           `yaml:"version" json:"version"`
    Defaults RouteSettings `yaml:"defaults" json:"defaults"`
    Routes   []Route       `yaml:"routes" json:"routes"`
    Jev      JevRuntime    `yaml:"jev" json:"jev"`

    Cascade  CascadeRuntime `yaml:"cascade" json:"cascade"`
}

func Parse(b []byte) (*Document, []FieldError)             // yaml.v3 Decoder.KnownFields(true); JSON accepted

```

```go
// internal/settings — versioned, hot-path-safe
type Version struct {
    ID int64; CreatedAt time.Time
    Source, Author, Message, SHA256, FileSHA256 string
    Doc *policy.Document; YAML string
}
type Snapshot struct{ Version Version; Effective *policy.Document; Locked, Persisted bool }
type Store interface { // Postgres implementation plus an in-memory one
    Latest(ctx context.Context) (*Version, error)
    List(ctx context.Context, limit int) ([]Version, error)
    Insert(ctx context.Context, v Version) (int64, error)
}
type Manager struct { /* atomic.Pointer[Snapshot], store, file path, seeds */ }
func (m *Manager) Active() *Snapshot // lock-free; called on every request
func (m *Manager) Propose(ctx context.Context, body []byte, baseID int64, author, msg string, dryRun bool) (*Version, []FieldError, error) // 409 if baseID != latest
func (m *Manager) Rollback(ctx context.Context, id int64, author string) (*Version, error)
func (m *Manager) Run(ctx context.Context)              // polls the file every POLICY_RELOAD_INTERVAL
func (m *Manager) Subscribe() <-chan *Snapshot         // gate/jev reconfigure; WS "config_changed"
```

**Boot and reload algorithm.**
1. Read the file and compute `fsha`.
2. If the file is missing, treat it as empty (built-ins plus seeds). If it's invalid, record the error, keep the active version (or bootstrap from built-ins), and set `policy.status=invalid`.
3. Load `latest` from the store.
4. If `latest` is nil, or `latest.FileSHA256 != fsha`, insert a `source=file` version with `FileSHA256=fsha`.
5. Otherwise keep `latest`.
6. When locked, the active version is always the file version.

Dashboard versions store the `fsha` observed at the time they were created, so an unchanged file never beats an edit made on top of it.

**Migration** (next free number, after the gateway's `gate_decisions`):
```sql
CREATE TABLE policy_versions (
  id BIGSERIAL PRIMARY KEY, created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  source TEXT NOT NULL CHECK (source IN ('file','dashboard','rollback','bootstrap')),
  author TEXT NOT NULL, message TEXT NOT NULL DEFAULT '',
  doc JSONB NOT NULL, yaml TEXT NOT NULL, sha256 TEXT NOT NULL, file_sha256 TEXT);
CREATE TABLE jev_spend (
  month TEXT NOT NULL, component TEXT NOT NULL,          -- 'gate' | 'cascade' | 'kb' | 'probe'
  usd NUMERIC(12,6) NOT NULL DEFAULT 0, calls BIGINT NOT NULL DEFAULT 0,
  input_tokens BIGINT NOT NULL DEFAULT 0, PRIMARY KEY (month, component));
```
Also fix the existing runner so each migration and its tracking insert run in one transaction (known gap at `postgres.go:50-96`).

### 1.4 `config/policies.yaml` (shipped example; the JSON schema drives editor autocompletion)

```yaml
# yaml-language-server: $schema=./policies.schema.json
version: 1
defaults:
  # mode: inherits TRUTHTABLE_GATE_DEFAULT_MODE (observe)   observe | flag | block | fallback
  # fail: inherits TRUTHTABLE_GATE_FAIL_MODE (open)          open | closed
  deadline_ms: 600
  # sample_rate: inherits TRUTHTABLE_JEV_SAMPLE_RATE (1.0)  -- applies to observe routes only
  stream_policy: passthrough          # passthrough | buffer
  context_from: [extension, tool_messages]
  thresholds: {flag_risk: 0.80, flag_contradiction: 0.70, block_contradiction: 0.95, block_min_confidence: 0.90}
  allow_uncalibrated: false           # block/fallback refuse to activate without a calibration file
routes:
  - name: support-bot
    match: {header: {X-TrustAgent-Route: support-bot}}
    mode: flag
  - name: payments-faq
    match: {header: {X-TrustAgent-Route: payments-faq}}
    mode: fallback
    stream_policy: buffer
    deadline_ms: 1500
    on_block: {action: fallback_message, message: "I can't confirm that from our policy documents. A human will follow up."}
jev:
  # enabled: inherits (resolved backend != off)
  # monthly_budget_usd: inherits TRUTHTABLE_JEV_MONTHLY_BUDGET_USD (5)
  question_set: gate-v1
  calibration: auto                   # auto = config/calibration/<snapshot>.json | off | <path>
audit:
  deep_audit: always                  # always | on_flag | sampled
  pass_sample_rate: 0.2
cascade:
  mode: auto                          # auto | llm | jev | cascade   (auto: cascade only if Jev is live AND calibrated)
  accept_confidence: {supported: 0.8, contradicted: 0.8, not_addressed: 0.8, partially_supported: 1.01}
  escalate_numeric: true
  shadow_rate: 0.05
```

**Seeds.** The `# ... inherits` comments are how `make configure` changes the default mode through `.env` without having to parse YAML (the wizard uses only the standard library).

**Invariants checked by `Validate`.**
- Each route's `name` is unique.
- `mode ∈ {observe, flag, block, fallback}`.
- Every threshold is in [0, 1] on a 0.01 grid.
- `deadline_ms` is in [50, 10000].
- `mode ∈ {block, fallback}` requires a resolved Jev backend other than `off`, **and** either a calibration file for the serving snapshot or `allow_uncalibrated: true`.
- `on_block` is required for `fallback`.

```
resolve(env):
  b = lower(TRUTHTABLE_JEV_BACKEND or "auto")
  if TRUTHTABLE_DEMO_MODE: return mock("demo mode forces mock: guaranteed $0")
  if b == "auto":
     OPENROUTER_API_KEY -> openrouter   ("OPENROUTER_API_KEY is set")
     elif TYPESAFE_API_KEY -> typesafe
     elif TRUTHTABLE_JEV_BASE_URL and TRUTHTABLE_JEV_API_KEY -> compatible
     else -> off ("no Jev key found; gateway runs in pass-through, see docs/JEV.md")
  key   = TRUTHTABLE_JEV_API_KEY or table[b].key_env
  base  = rstrip("/", TRUTHTABLE_JEV_BASE_URL or table[b].base)
  model = TRUTHTABLE_JEV_MODEL or table[b].model

     explicit b needs a key it doesn't have (never silently switch backends)
```

`testdata/config/jev_resolve_cases.json` holds about 25 `{env, expected}` cases. Go (`config`), Python (`truthtable.jev.settings`) and `scripts/doctor.py` all run that same file in their tests, which guarantees they resolve identically.

**Status state machine.** Exported through `/health/ready`, the WS `system_status` message, and the gauge `trustagent_jev_status{state}`.

- **States:** `off`, `mock`, `checking`, `ready`, `degraded` (errors below the breaker threshold), `breaker_open`, `unauthorized` (401/403), `no_credits` (a 402 that isn't the in-flight budget case), `budget_exhausted` (the local cap), `misconfigured`, `unreachable`.
- **Sticky states:** `unauthorized` and `no_credits` persist until a config reload, the admin endpoint `POST /api/admin/jev/recheck`, or a free re-check every 5 minutes.
- **Startup check:** free and async.
  - OpenRouter: `GET https://openrouter.ai/api/v1/key` for validity plus `limit`/`limit_remaining` **[A2: exact response shape]**.
  - TypeSafe: `GET /v1/models` **[A3]**.
  - The billed probe runs only from the doctor or the Test button.

**Snapshot drift.** The `model` value in each response is logged and exported as `trustagent_jev_snapshot_info{snapshot}`. If the calibration file names a different snapshot, `trustagent_jev_calibration_stale` goes to 1. The dashboard then shows a banner, and routes that need calibration (block and fallback) **downgrade to flag**. The downgrade is recorded as a reason and never happens silently.

**Budget.**
- **Spend per call:** `usage.cost`, or `input_tokens × TRUTHTABLE_JEV_PRICE_PER_MTOK/1e6` when `cost` is missing. The price per million tokens is configurable because alpha pricing may change.
- **Accumulation:** spend is added in memory and upserted to `jev_spend` every 10 s, keyed by UTC month.
- **Python's spend:** Python reports cascade spend in `AuditResult` **[contract]**, and Go adds it to the same total.
- **Pre-call check:** if `spent + estimate > budget`, the call is skipped. The gate records `skipped:budget`, and Go sends `options.jev_enabled=false` to Python.
- **Warnings:** at 80%, a warning and a metric.
- **Reset:** at 100% Jev pauses until the month rolls over or the budget is raised in the dashboard. `0` means unlimited.
- The OpenRouter per-key credit limit is the hard cap on the provider side; this budget is a second, independent safeguard.

### 1.6 Admin API and health **[contract with the frontend designer]**

**Auth.**
- `TRUTHTABLE_ADMIN_KEY` can't be set at build time, so it can't end up in the bundle; the user types it into Settings and it is kept in `sessionStorage`.
- If neither `TRUTHTABLE_API_KEYS` nor `TRUTHTABLE_ADMIN_KEY` is set (dev mode), admin endpoints are open and the UI shows a permanent "Admin API unauthenticated (dev mode)" banner.
- If API keys are set but no admin key is, admin endpoints return `403 "set TRUTHTABLE_ADMIN_KEY"`. This is secure by default.

| `GET /api/admin/config` | Every registry key: `{key, display, source, restart, secret}`, plus `warnings[]` and `dotenv_path`. |
| `GET /api/admin/policies` | `{active: Version, file: {path, sha, status, error}, locked, persisted}` |
| `GET /api/admin/policies/versions?limit=50` | Version history. |

| `PUT /api/admin/policies` | `{yaml, base_version, message}`. Returns 200, or 409 (stale), 422 (field errors), 423 (locked). |

`/health/ready` components:
- `engine`: gRPC `HealthCheck` with a 1 s deadline, cached for 5 s. This fixes M4: `/health` currently reports `auditClient != nil`.
- `database` (ping plus the migration version), `redis`, `jev`, `policy`, `upstream` (HEAD, cached for 30 s).
- Hints are only included for admin callers or in dev mode.

## 2. `make configure`: `scripts/configure.py`

**Constraints.** Standard library only, Python 3.9 or later. Invoked as `$(PYTHON) scripts/configure.py`, where `PYTHON ?= python3` (or `py -3` on Windows).

**Interface.**
```
configure.py [--env-file .env] [--preset demo|local|cloud] [--non-interactive]
             [--set KEY=VALUE ...] [--ensure] [--dry-run] [--probe/--no-probe]
```
`--ensure` creates `.env` from `.env.example` if it is missing, fills in required generated values, and never overwrites anything.

**Flow (interactive).** Each step shows the current value, masked for secrets; Enter keeps it.

1. **Preset:**
   - Demo: no keys, mock everything.
   - Local: Ollama judge and upstream, `COMPOSE_PROFILES=local-llm`.
   - Cloud: Anthropic judge and an OpenRouter upstream or Jev.
2. **Judge:** `anthropic`, `openai` or `ollama`. Keys are read with `getpass`. The prefix is sanity-checked (`sk-ant-`), which only warns. Then choose `LLM_FALLBACK`.
3. **Jev backend:**
   - Recommended: auto (OpenRouter).
   - Others: OpenRouter System One route, TypeSafe direct, Vercel AI Gateway (fills in the base URL and model), custom compatible, mock, off.
   - Paste the key (`sk-or-v1-` prefix check; a warning only).
   - Asks "Run a live probe now? costs ≈ $0.00001 [y/N]", which calls the same probe function as the doctor.
4. **Upstream LLM:** `ollama`, `https://api.openai.com`, `https://openrouter.ai/api` or a custom URL. Anthropic `/v1/messages` is marked "not supported in 2.0". Optional `TRUTHTABLE_UPSTREAM_API_KEY`.
5. **Default policy mode:** `observe` (recommended), `flag`, `block` or `fallback`, written to `TRUTHTABLE_GATE_DEFAULT_MODE`.
   - Choosing block or fallback prints: "Blocking needs calibrated thresholds: the proxy will downgrade to flag until `make calibrate` has produced a file for your Jev snapshot."
   - It refuses outright when Jev is `off`.
6. **Security:**
   - Optionally generate `TRUTHTABLE_API_KEYS` (`secrets.token_hex(32)`) and `TRUTHTABLE_ADMIN_KEY`.
   - If empty, generate `GRAFANA_ADMIN_PASSWORD`, and `POSTGRES_PASSWORD` **only when `.env` was just created**, with the warning "changing this later breaks an existing postgres volume".
7. **Compose profiles:** computes `COMPOSE_PROFILES`: `local-llm` if the judge or upstream uses Ollama, plus `observability` if requested.
8. **Summary:** a diff with secrets masked. Offers to run `make doctor`.

**Writing.**
- A line-preserving editor keeps comments, ordering and unknown keys. It updates keys in place and appends new ones under `# --- added by make configure (date) ---`.
- Backs up to `.env.bak`, writes to a temp file then `os.replace`, and runs `chmod 600` on POSIX.
- Migrates `UPSTREAM_LLM_URL` to `TRUTHTABLE_UPSTREAM_URL` after asking.
- Never prints a secret. The only network call is the optional probe.

**Failure behaviour.** Ctrl-C leaves the file untouched. An unreadable `.env` prints the line number and exits 2. Non-interactive runs with missing required answers exit 2 and list them.

## 3. `make doctor`: `scripts/doctor.py`

**Constraints.** Standard library only: `urllib`, `socket`, `json`, `subprocess`, `ssl`.

**Interface.**
```
doctor.py [--target auto|docker|host] [--no-probe] [--json] [--only ID,...] [--skip ID,...] [--expect demo]
```
- Exit 0 means no FAIL results; exit 1 means at least one FAIL.
- Colour output is turned off by `NO_COLOR` or when stdout isn't a TTY.
- `auto` picks `docker` if `docker compose ps --format json` shows the proxy running.

Each check returns `{id, status: PASS|WARN|FAIL|SKIP, summary, detail, fix}`. The `fix` field is a command you can paste.

| ID | What it checks | Typical fix it prints |
|---|---|---|
| `env.file` | `.env` exists; required keys present; mode 0600 | `make configure` / `chmod 600 .env` |
| `env.unknown_keys` | Misspelled `TRUTHTABLE_*` keys (same Levenshtein suggestion as the services) | "rename X to Y" |
| `tools.*` | `docker compose version` (v2), and for host mode go ≥ go.mod, python 3.11, poetry, node ≥ 22.12, protoc | Install links |
| `stubs.generated` | Host mode: `backend-go/api/audit/v1/*.pb.go` and the `pb/*_pb2.py` files exist | `make proto-tools proto` |
| `compose.services` | Health of every running container | `docker compose logs <svc>` |
| `proxy.live` / `proxy.ready` | `/health`, then `/health/ready` (component details) | Per component |
| `engine.grpc` | From `/health/ready.engine`; falls back to `docker compose exec -T audit-engine python -m truthtable.healthcheck` | Engine logs; start period |
| `db.postgres` | `/health/ready.database`; else TCP connect plus `docker compose exec -T postgres pg_isready` | `make up` (now includes postgres) |
| `cache.redis` | Raw socket `PING` → `+PONG` | — |
| `kb.qdrant` | `GET :6333/readyz`, collection `truthtable_knowledge`, count | Seed hint |
| `judge.provider` | Anthropic `GET /v1/models` (`x-api-key`, free); OpenAI `GET /v1/models`; Ollama `/api/tags` contains `OLLAMA_FALLBACK_MODEL` | `make ollama-pull` |
| `upstream.reach` | `ollama`: `/api/tags`; otherwise TLS and HEAD on the base URL | — |
| `jev.resolve` | Runs the shared resolution; prints the backend and **why** it was chosen | Wizard step 3 |
| `jev.key` | Free check (§1.5) → valid, limit remaining | Key page URL |
| `jev.probe` | One-question billed call (below) unless `--no-probe` | See the error map |
| `jev.calibration` | A calibration file exists for the snapshot returned by the probe (or the last logged one) | `make calibrate` |
| `policy.file` | `/api/admin/policies` status; host mode without a proxy: `go run ./cmd/proxy -check-config` if Go is available | Field errors with line numbers |
| `obs.targets` | Prometheus `/api/v1/targets` (observability profile only) | — |

**Probe body.** About 275 input tokens × $0.042 per million ≈ **$0.0000116**.
```json
{"model":"<resolved>","state":{"note":"TrustAgent doctor connectivity probe"},
 "questions":{"probe":{"type":"noul","instructions":"Does `note` describe a connectivity probe?"}}}
```
It validates `Content-Type: application/json`, that `answers.probe.noul` is in [0, 1], and records latency, the `model` snapshot and `usage.cost`.

| Probe result | Diagnosis printed |
|---|---|
| 401 or 403 | Key invalid or revoked; create one at openrouter.ai/settings/keys (or console.typesafe.ai/keys) |
| 402 | No credits, or the key's limit is reached: openrouter.ai/settings/credits, or raise the key's limit. An in-flight 402 is reported as transient. |
| 200 `text/html` or 404 | Base URL is wrong; OpenRouter URLs must end in `/api` |
| 413 | Should never happen for the probe; reported as an adapter bug |
| 429 | Rate limited; retry later |
| 5xx, 524, 529 | Provider problem, not your configuration |
| Timeout (5 s) | Network problem, or an alpha endpoint hang (reported for about 15% of calls); retry |

`--expect demo` (used in CI) asserts that Jev is `mock`, the judge is `mock`, and **no** billed call is made.

## 4. `make demo`, the traffic generator and recordings

**`make demo` needs only Docker.**
```make
demo: ## Full stack with mock Jev + mock judge + scripted traffic. No keys, $0.
	$(PYTHON) scripts/configure.py --ensure --non-interactive
	$(COMPOSE) -p $(DEMO_PROJECT) -f docker-compose.yml -f docker-compose.demo.yml --profile demo up -d --build --wait
	@echo "Dashboard: http://localhost:$${DASHBOARD_HOST_PORT:-3000}  (DEMO MODE)"
	-$(PYTHON) scripts/open_url.py http://localhost:$${DASHBOARD_HOST_PORT:-3000}
demo-down: ; $(COMPOSE) -p $(DEMO_PROJECT) -f docker-compose.yml -f docker-compose.demo.yml --profile demo down
```

**Isolation.**
- `-p trustagent-demo` gives the demo its own volumes, so scripted audits never mix with real history. This requires removing every `container_name:` from `docker-compose.yml`; the Makefile switches to `$(COMPOSE) exec <svc>`.
- `docker-compose.demo.yml` **blanks** `OPENROUTER_API_KEY`, `TYPESAFE_API_KEY`, `ANTHROPIC_API_KEY` and `OPENAI_API_KEY` for every service, which guarantees $0 of spend.
- It sets: `TRUTHTABLE_DEMO_MODE=true`, `TRUTHTABLE_JEV_BACKEND=mock`, `TRUTHTABLE_JEV_MOCK_FIXTURES=/demo/fixtures/jev.json`, `LLM_PROVIDER=mock`, `MOCK_FIXTURES_PATH=/demo/fixtures/judge.json`, `LLM_FALLBACK=none`, `TRUTHTABLE_TEST_MODE=true`, `TRUTHTABLE_CALIBRATION_DIR=/demo/calibration`, `TRUTHTABLE_STRICT_CONFIG=true`.
- It mounts `./demo:/demo:ro` into the proxy and engine, and adds the `traffic` service (profile `demo`): `python:3.11-slim` running `python /scripts/traffic.py --loop --interval 4 --jitter 0.5`. It depends on the proxy and audit-engine both being `service_healthy`.
- The demo can't run at the same time as the real stack on the same ports; `demo-down` comes first (documented).

**`demo/` layout.**
- `scenarios.json`: the single source of truth.
- `fixtures/jev.json` and `fixtures/judge.json`: generated.
- `calibration/mock-jev-1.json`, so block and fallback work in the demo.
- `recordings/*.json`.

`scenarios.json`:
```json
{"schema":"trustagent.scenarios/v1","scenarios":[
 {"id":"refund-grounded","route":"support-bot","stream":false,
  "messages":[{"role":"user","content":"What is the refund window for annual plans?"}],
  "context":[{"id":"kb-112","text":"Annual plans can be refunded within 30 days of purchase."}],
  "response":"Annual plans can be refunded within 30 days of purchase.",
  "expect":{"gate_action":"pass","verdicts":["SUPPORTED"]}}]}
```
Plan about 12 scenarios: grounded; unsupported (flag); contradiction on `payments-faq` (fallback); numeric/date (escalation); refusal; small talk (`no_factual_content`); prompt injection in the context; streamed; too long (`not_assessed:too_long`); non-English; no context (`not_assessed`); multi-claim with a partial.

`backend-python/evals/build_demo_fixtures.py` generates both fixture files from `scenarios.json`. CI checks that the generated files are up to date (`--check`), so the mocks can't drift from the scenarios.

**`scripts/traffic.py`** (standard library).
```
traffic.py --base-url URL --scenarios FILE (--loop|--once) [--interval S] [--jitter F]
           [--api-key K] [--expect]
```
- Each request goes to `/v1/chat/completions` with `test_response`, the context extension field **[contract: gateway designer names it, e.g. `trustagent.context`]**, `X-TrustAgent-Route`, a unique `X-Request-ID` (avoids B4), and `X-TrustAgent-Demo: scripted`.
- With `--expect`, it asserts the `X-TrustAgent-Gate` value against `expect.gate_action` and exits 1 on a mismatch. CI uses this as an HTTP contract test.

**Recordings for the static Pages demo.**
- `make record-demo`:
  1. Requires real keys; refuses to run in demo mode unless `ALLOW_MOCK=1`.
  2. Runs `traffic.py --once`, waits for every audit to complete, then exports through `/api/audits?include=gate`.
  3. Writes `demo/recordings/<source>-<YYYYMMDD>.json`.
- Schema:
```json
{"schema":"trustagent.demo-recording/v1","source":"live|mock","recorded_at":"…","git_sha":"…",
 "versions":{"trustagent":"2.0.0","jev_backend":"openrouter","jev_snapshot":"typesafe/jev-1.13-20260917","judge":"anthropic/claude-haiku-4-5"},
 "totals":{"jev_usd":0.0031,"audits":12},
 "events":[{"t_ms":0,"type":"gate_decision","data":{…}},{"t_ms":2140,"type":"audit_result","data":{…}}]}
```
- The recorder strips all headers and keys; scenario content is synthetic.
- `scripts/check_recording.py` fails the Pages build if `source`, `recorded_at` or `versions` is missing.
- The frontend's `ReplayTransport` implements the same interface as the WebSocket transport, and the UI shows **"Recorded {date} · live Jev {snapshot} + {judge}"**, or **"Simulated (mock Jev) — not real model output"** when `source=mock`.
- Until the owner has keys, Pages ships the mock recording with that label.

## 5. Compose, Dockerfiles, Makefile, repo hygiene

### 5.1 Compose changes

1. **Profiles.**
   - Default: `redis`, `postgres`, `qdrant`, `audit-engine`, `proxy`, `dashboard`.
   - `local-llm`: `ollama`, plus `ollama-init`, a one-shot job that runs `ollama pull ${OLLAMA_FALLBACK_MODEL:-llama3.2:1b}`. This removes the manual step and the model-name mismatch. Cloud-only users skip the 2 GB+ model.
   - `observability`: `prometheus`, `grafana`.
   - `demo`: `traffic`.
   - **[A5]** Compose may evaluate `${GRAFANA_ADMIN_PASSWORD:?}` even when the grafana profile is inactive. Mitigation: `make demo`, `make up` and `make up-all` all call `configure.py --ensure` first, which generates the password.
2. **Engine healthcheck.** A new `backend-python/src/truthtable/healthcheck.py` calls the existing `HealthCheck` RPC on `localhost:$GRPC_PORT` with a 2 s deadline. It exits 0 if the server answers, even when dependencies are degraded, because the engine degrades gracefully. No new dependency is needed.
   ```yaml
   healthcheck: {test: ["CMD","python","-m","truthtable.healthcheck"], interval: 10s, timeout: 5s, retries: 5, start_period: 180s}
   ```
3. **`depends_on` conditions.**
   - engine → `redis`, `qdrant`: `service_healthy`; `ollama`: `{condition: service_healthy, required: false}` **[A6: Compose ≥ 2.20]**.
   - proxy → `postgres`, `redis`: `service_healthy`; `audit-engine`: `service_started`. The proxy degrades without the engine, and the `/health/ready` check makes that visible.
   - dashboard → `proxy`: `service_healthy`.
4. **Build contexts include proto.** `build: {context: ./backend-go, additional_contexts: {proto: ./proto}}`, and the same for the engine **[A7: Compose ≥ 2.17]**. The stubs are generated inside the images:
   - Go: `FROM golang:1.25-alpine AS proto`, `apk add protobuf protobuf-dev`, pinned plugin installs (the same pins as the Makefile), `protoc` into `/out`, then `COPY --from=proto`.
   - Python: `grpc_tools.protoc` in the builder stage, since `grpcio-tools` is already a dependency.

   Together these make a fresh clone buildable with nothing but Docker.
5. **Python Dockerfile.** The builder installs from `poetry.lock`: `pip install poetry==2.4.1`, `POETRY_VIRTUALENVS_IN_PROJECT=1 poetry install --only main --no-root --no-interaction`. This picks up the CPU torch from the explicit source and fixes F5. It then copies `.venv`. `ARG VERSION` is used as a label.
6. **Go Dockerfile.** `ARG VERSION`, and `-ldflags "-s -w -X …/internal/version.Version=${VERSION}"`. Remove `EXPOSE 8081`.
7. **Dashboard image.**
   - `ARG VITE_APP_MODE=full`, `ARG VITE_BASE_PATH=/`.
   - Runtime stage: `nginxinc/nginx-unprivileged:<pinned>-alpine` **[A8: current tag]**, which closes the known "dashboard nginx not non-root" gap.
   - `nginx.conf` becomes a template (`/etc/nginx/templates/default.conf.template`, envsubst from `PROXY_UPSTREAM=http://proxy:8080`). It proxies `/api/`, `/ws` (with upgrade headers) and `/health` to the proxy, so the browser uses **same-origin relative URLs**: no CORS, no build-time URLs, and the WS origin is already on the allowlist.
   - `docker/40-runtime-config.sh` (in `/docker-entrypoint.d/`) writes `/tmp/runtime-config.js` (`window.__TRUSTAGENT__={apiUrl,wsUrl,mode}`) from `DASHBOARD_*`. It is served by `location = /runtime-config.js { alias /tmp/runtime-config.js; }`, because the html directory isn't writable by a non-root user.
   - CSP adds `connect-src 'self'`.
   - The dashboard key is typed into Settings and never compiled in.
8. **Other Compose changes.**
   - The proxy mounts `./config:/etc/trustagent:ro`, with `TRUTHTABLE_POLICY_FILE=/etc/trustagent/policies.yaml` and `TRUTHTABLE_CALIBRATION_DIR=/etc/trustagent/calibration`.
   - Pass through the new Jev, gate and admin keys (for example `OPENROUTER_API_KEY=${OPENROUTER_API_KEY:-}`) to the proxy **and** the engine only.
   - Ports: `"${PROXY_HOST_PORT:-8080}:8080"` and `"${DASHBOARD_HOST_PORT:-3000}:3000"`.
9. **Prometheus.**
   - Add `extra_hosts: ["host.docker.internal:host-gateway"]`.
   - Python metrics are renamed `trustagent_engine_*`. Go keeps the end-to-end and gateway metrics under `trustagent_*`.
   - Every Grafana query gets `job=` filters, which fixes the double counting (F15). Add gate and Jev panels.
   - This is a breaking change, listed in the 2.0.0 CHANGELOG.
10. **New files.**
    - `.dockerignore` for each context. The frontend one excludes `node_modules`, `dist*` and `e2e/`; the Python one excludes `.venv` and `**/__pycache__`.
    - Root `.gitattributes` (`* text=auto eol=lf`, `*.sh eol=lf`, `Makefile eol=lf`, `*.png binary`), so Windows checkouts don't break shell entrypoints.
    - `.gitignore` gets `frontend-react/dist-pages/`, `frontend-react/playwright-report/` and `frontend-react/test-results/`.

## 6. Documentation

### 6.1 `docs/JEV.md` (plain language, for the owner)

1. **What Jev is, in one paragraph.** A very fast, very cheap multiple-choice grader from TypeSafe AI, launched 2026-09-15. It doesn't write text. It answers typed questions (yes/no, pick one, rate on a scale) with probabilities.
2. **Why it's in the gateway.**
   - It answers in about 0.2–0.5 s for fractions of a cent, so it can check every response inline.
   - The slow, explaining LLM audit still runs afterwards and streams to the dashboard.
   - When they disagree, that counts as an uncertainty signal.
3. **Do I need anything?** For the demo, no (`make demo`). For real checks, an OpenRouter account and a key. **No TypeSafe account and no waitlist.**
4. **Step by step through OpenRouter.**
   1. Go to https://openrouter.ai and sign in.
   2. Add credits at https://openrouter.ai/settings/credits (about $5 is plenty; OpenRouter adds a small payment fee).
   3. At https://openrouter.ai/settings/keys, click **Create Key**. Name it "TrustAgent local" and **set a credit limit** (for example $2), which caps what the key can spend. Copy the key. It typically starts with `sk-or-v1-` and is shown only once.
   4. Run `make configure`, choose "Jev → OpenRouter (recommended)" and paste the key (it isn't echoed). Or add `OPENROUTER_API_KEY=…` to `.env` by hand.
   5. Run `make doctor`. You should see something like `jev.probe PASS typesafe/jev-1.13-2026…, 231 ms, $0.0000116`.
   6. Restart with `docker compose up -d` (or restart the dev processes).
   7. In Dashboard → Settings → Jev you should see "Connected via OpenRouter".
   8. Never put the key in the frontend, a screenshot or a commit. gitleaks in CI blocks commits that contain it.
5. **Alternatives.**
   - **TypeSafe direct:** keys at https://console.typesafe.ai/keys (early access, separate billing). Set `TYPESAFE_API_KEY` and use model `jev-1.13.0`.
   - **Vercel AI Gateway:** the `compatible` preset, marked unverified; check it with `make doctor`.
   - **OpenRouter System One route:** a fallback in case `/alpha/decisions` changes (`TRUTHTABLE_JEV_BACKEND=openrouter-systemone`).
6. **Modes (`off`, `mock`, live) and what happens when things break.**
   - The gateway always fails open unless a route sets `fail: closed`. The response header shows `X-TrustAgent-Gate: skipped` and the dashboard shows why.
   - The Jev status table is the same one as in §1.5.
7. **Costs, worked through (at $0.042 per million input tokens; output is free; alpha pricing may change).**

   | Use | Tokens | Cost |
   |---|---|---|
   | Gate check: ~250 overhead + ~600 for 4 questions + 3,700 of prompt, response and context | ≈ 4,550 | **$0.00019**, i.e. $0.19 per 1,000 responses, or about $57/month at 10k responses/day |
   | Cascade (8 claims × ~3,580 tokens) | ≈ 28,600 | **$0.0012 per audit** |
   | Doctor probe | ≈ 275 | $0.0000116 |

   **$5 buys** about 26,000 gated responses, or about 4,100 fully Jev-verified audits. For comparison, an LLM-only Haiku judge was estimated at about $35 per 1,000 audits (an estimate).

   There are two safeguards: the OpenRouter key limit (a hard cap) and `TRUTHTABLE_JEV_MONTHLY_BUDGET_USD` (a soft cap, 80% warning, default $5).
8. **Limits.**
   - Latency: 70–500 ms per the vendor; about 0.23 s p50 on OpenRouter.
   - About 15% of calls reportedly hang on the alpha endpoint, so there are hard timeouts, retries and a circuit breaker.
   - A 32k-token budget (TrustAgent uses 24k).
   - 1,200 requests/min on TypeSafe direct (TrustAgent caps at 18 per second).
   - An errors table.
9. **Limitations.**
   - It gives no explanations.
   - It is weak at arithmetic, counting, numbers, dates and double negatives; such claims escalate to the LLM.
   - Large amounts of irrelevant context lower accuracy.
   - It is **not a security boundary**: prompt injection inside the state works.
   - It is English-first.
   - There is no published calibration, and thresholds drift from one snapshot to the next.
10. **Calibration (`make calibrate`).**
    1. Run in observe mode until you have at least 200 labels per class. Labels come from deep-audit verdicts (labelled "agreement", not accuracy), from human "Label" clicks in the dashboard, and optionally from a public dataset (`DATASET=ragtruth`).
    2. Run `make calibrate` for a dry-run report: ECE, Brier score, a reliability table, and a threshold sweep aimed at a false-block rate of 1% or less.
    3. Run `make calibrate WRITE=1`. This writes `config/calibration/<snapshot>.json`.
    4. The proxy loads it automatically (`calibration: auto`), and block and fallback routes become eligible.
    5. Repeat whenever the dashboard says the snapshot changed.
11. **Privacy.** Prompt, response and context go to OpenRouter and then TypeSafe. Individual routes can opt out (`jev: false`). There is the ZDR flag. Keys never reach the browser.
12. **Troubleshooting and FAQ.** "Is Jev an LLM?", "Can I use `jev-latest`?" (yes, but recalibrate each time), and similar.

### 6.2 `make calibrate`: `backend-python/evals/calibrate.py` (numpy only)

```
python -m evals.calibrate --source api|file|dataset [--input X.jsonl] [--dataset ragtruth]
       [--question-set gate-v1] [--min-labels 200] [--target-false-block 0.01]
       [--max-cost-usd 0.50] [--write] [--out config/calibration]
```

**Method.**
- Per question: isotonic regression when n ≥ 500 (pool-adjacent-violators, about 30 lines), otherwise Platt scaling (a 2-parameter Newton solve).
- Output is a 101-point lookup table, which Go applies by linear interpolation.
- Metrics: 10-bin ECE, Brier score and reliability bins before and after calibration.
- Threshold sweep on a 0.01 grid, reporting precision and recall for flag and the false-block rate for block.

**Output file.**
```json
{"schema":"trustagent.calibration/v1","jev_model_snapshot":"…","question_set":"gate-v1","created_at":"…",
 "label_source":{"human":212,"deep_audit":1840},
 "questions":{"unsupported_content":{"method":"isotonic","n":2052,"ece_before":0.11,"ece_after":0.03,
   "brier_before":0.09,"brier_after":0.07,"table":[/*101*/],"reliability":[{"bin":0.05,"pred":0.04,"obs":0.06,"n":311}]}},
 "recommended_thresholds":{"flag_risk":{"value":0.78,"precision":0.90,"recall":0.71},
   "block_contradiction":{"value":0.96,"false_block_rate":0.008}},
 "warnings":["contradicts_context: 83 positives (< 200): provisional"]}
```

**Refusals.**
- Refuses to `--write` below `--min-labels` unless `--force`.
- `--source api` pulls `GET /api/gate/decisions?labelled=true&format=jsonl` **[contract: gateway designer]** with the admin key.
